# Czo Show Password

## Extension for Chromium and Firefox

Show password when double-clicking over password fields.

Key Features:
- Double-click password fields to toggle between hidden and visible text.
- Double-click again to return the field to password mode.
- Automatically hides the password when the field loses focus.
- Runs automatically on HTTP and HTTPS web pages without manual activation.
- Detects dynamically added password fields after page load.
- Works in all frames and keeps the experience focused with no extra interface.

I made a clone because I don't want my passwords to be stolen if a non-personal automatic update occurs.

Privacy: - No personal data collected.
